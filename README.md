# ClientPro — تطبيق إدارة العملاء للآيفون

تطبيق iOS أصلي (SwiftUI + SwiftData) لإدارة العملاء والمبيعات، بالعربي بالكامل ومن اليمين لليسار، ومصمم بحيث تقدر تبيعه لعملائك وكل واحد يخصصه باسم نشاطه وشعاره وألوانه.

## المميزات

| القسم | اللي فيه |
|---|---|
| **لوحة التحكم (Dashboard)** | إيرادات الشهر ونسبة النمو، صافي الربح، المستحقات، عدد العملاء، الصفقات المفتوحة، رسم بياني للإيرادات والمصروفات آخر ٦ شهور، هدف الشهر، مسار المبيعات، توزيع العملاء، أفضل العملاء، مهام اليوم، فواتير متأخرة، مخزون منخفض، وأزرار إضافة سريعة |
| **العملاء** | ملف كامل لكل عميل (صورة، شركة، هاتف، واتساب، بريد، عنوان، مصدر، وسوم، تقييم، تاريخ ميلاد، **حقول مخصصة** تضيفها بنفسك)، بحث وفلترة وترتيب، مفضلة، استيراد من جهات الاتصال، اتصال/واتساب/SMS/بريد/خريطة بضغطة، سجل تواصل، تصدير Excel |
| **الفواتير** | فواتير بأكثر من بند، خصم وضريبة، مسودة/إصدار/إلغاء، تسجيل دفعات جزئية بطرق دفع مختلفة (نقدي، InstaPay، محفظة، تحويل...)، حالات تلقائية (مدفوعة، جزئية، متأخرة)، **PDF احترافي بشعارك** للمشاركة، رسالة تذكير على واتساب، نسخ الفاتورة، تصدير Excel |
| **الصفقات** | مسار مبيعات (جديدة ← تواصل ← عرض سعر ← تفاوض ← مكسب/خسارة)، احتمالية الإغلاق، القيمة المرجّحة، نسبة النجاح، تحويل الصفقة المكسوبة لفاتورة |
| **المهام** | مهام مرتبطة بالعملاء، أولويات، مواعيد، **تذكير بإشعار**، تأجيل بسحبة، تقسيم (متأخرة/اليوم/قادمة) |
| **المنتجات والخدمات** | أسعار وتكلفة وهامش ربح، متابعة المخزون وتنبيه عند النقص، خصم تلقائي من المخزون عند الفوترة |
| **المصروفات** | تصنيفات، تجميع شهري، تصدير Excel |
| **التقارير** | حسب الفترة: المحصّل، المصروفات، صافي الربح، متوسط الفاتورة، أعلى العملاء، أكثر المنتجات مبيعاً، توزيع المصروفات، مصادر العملاء |
| **الإعدادات** | اسم النشاط وشعاره وبياناته (تظهر في الفاتورة)، العملة (١٤ عملة عربية وعالمية)، ترقيم الفواتير، الضريبة الافتراضية، الوضع الفاتح/الداكن، ٩ ألوان للتطبيق، أرقام عربية أو إنجليزية، **قفل Face ID**، بيانات تجريبية، حذف كل البيانات |

كل البيانات محفوظة على جهاز المستخدم (بدون سيرفر ولا اشتراكات).

## التشغيل

المطلوب: جهاز Mac عليه **Xcode 16 أو أحدث**، والآيفون يكون iOS 17 أو أحدث.

1. افتح `ClientPro.xcodeproj` في Xcode.
2. من **Signing & Capabilities** اختر الـ Team بتاعك (حساب Apple).
3. غيّر **Bundle Identifier** لحاجة خاصة بيك، مثلاً `com.yourname.clientpro`.
4. وصّل الآيفون واضغط ▶️ Run.

أول ما التطبيق يفتح هيسألك عن اسم النشاط والعملة، وتقدر تبدأ ببيانات تجريبية عشان تشوف كل حاجة شغالة.

## تخصيص التطبيق لكل عميل تبيعه له

- **الاسم الظاهر تحت الأيقونة**: من إعدادات الـ Target ← `Display Name`.
- **الأيقونة**: استبدل `ClientPro/Assets.xcassets/AppIcon.appiconset/AppIcon.png` بصورة 1024×1024.
- **اسم النشاط والشعار والألوان والعملة**: العميل يغيرها بنفسه من داخل التطبيق (المزيد ← الإعدادات).
- **رفع التطبيق على App Store أو TestFlight**: من Xcode ← Product ← Archive.

## هيكل المشروع

```
ClientPro/
├── App/            نقطة البداية، التابات، شاشة القفل، شاشة الترحيب
├── Models/         نماذج البيانات (عميل، صفقة، فاتورة، دفعة، منتج، مهمة، تواصل، مصروف)
├── Services/       التنسيق، الإعدادات، PDF، Excel، واتساب/اتصال، Face ID، الإشعارات، البيانات التجريبية
├── Components/     عناصر واجهة مشتركة
└── Views/          الشاشات (الرئيسية، العملاء، الفواتير، الصفقات، المهام، المنتجات، المصروفات، التقارير، الإعدادات)
```

الملفات الجديدة اللي تضيفها جوه فولدر `ClientPro/` بتدخل المشروع تلقائياً.
