# 🍽️ سيستم إدارة طلبات المطعم

سيستم كامل لإدارة طلبات المطاعم والفروع، **بيشتغل على الكمبيوتر والموبايل** من نفس المكان، وكل الأجهزة مربوطة ببعض لحظياً.

## المميزات

| الميزة | التفاصيل |
|---|---|
| 📋 **المنيو والأسعار** | أقسام وأصناف وأسعار وصور، وقفل أي صنف خلص بضغطة |
| 📞 **تسجيل الطلبات** | شاشة سريعة للكول سنتر/الكاشير: تكتب رقم الموبايل يطلعلك العميل وعناوينه وآخر طلباته تلقائياً، وزرار "كرر آخر طلب" |
| 👤 **بيانات العملاء** | الاسم، رقمين موبايل، أكتر من عنوان (المنطقة + العنوان + علامة مميزة)، ملاحظات، وتاريخ كل الطلبات |
| ⚡ **إرسال الطلب للفرع فوراً** | أول ما الطلب يتسجل يظهر عند الفرع **في نفس اللحظة** مع صوت تنبيه وإشعار - من غير ما حد يعمل تحديث |
| 🚦 **متابعة حالة الطلب** | جديد ← تم القبول ← جاري التحضير ← جاهز ← مع الطيار ← تم التسليم (أو ملغي بسبب)، ولوحة كانبان، وسجل كامل مين عمل إيه وإمتى |
| 🔗 **رابط متابعة للعميل** | العميل يتابع طلبه من الموبايل، وتقدر تبعتله الرابط على واتساب بضغطة |
| 🏪 **أكتر من فرع** | كل فرع بمصاريف توصيل خاصة، وتحويل طلب من فرع لفرع، وكل فرع يشوف طلباته بس |
| 🛵 **الطيارين** | تعيين طيار للطلب، والطيار يشوف طلباته بس ويحدث "خرج للتوصيل" و"تم التسليم" من موبايله، مع زرار الخريطة والاتصال |
| 🔐 **حسابات وصلاحيات** | أدوار جاهزة (مدير عام، مدير فرع، كول سنتر، مطبخ، طيار) وتقدر تعدل صلاحيات أي دور أو تعمل أدوار جديدة |
| 📊 **لوحة تحكم للإدارة** | المبيعات، عدد الطلبات، متوسط الطلب، متوسط وقت التسليم، الطلبات الشغالة دلوقتي، المبيعات حسب اليوم/الساعة/الفرع، الأصناف الأكتر مبيعاً، أفضل العملاء |
| 🖨️ **طباعة الفاتورة** | فاتورة مقاس طابعة الكاشير (80 مم) |
| 📱 **موبايل + تطبيق** | الواجهة متظبطة للموبايل، وتتثبت كتطبيق على الشاشة الرئيسية، ومعاها مشروع تطبيق أندرويد/آيفون جاهز |
| 🌙 **وضع ليلي** | تلقائي حسب الجهاز أو تختاره بنفسك |

## 🚀 التشغيل (خطوة بخطوة)

### 1) سطّب Node.js
نزّل **Node.js 22 LTS أو أحدث** من https://nodejs.org وسطّبه (Next ← Next ← Finish).

### 2) شغّل السيستم
- **ويندوز:** دبل كليك على ملف **`start.bat`**
- **ماك / لينكس:** افتح Terminal في الفولدر واكتب `./start.sh`

أو يدوياً:
```bash
npm install
npm start
```

أول مرة هياخد دقيقة يسطّب الحاجات، وبعدها هيفتح المتصفح على `http://localhost:3000`.

### 3) سجّل دخول
| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `admin` | `admin123` | مدير عام (كل الصلاحيات) |
| `manager1` | `123456` | مدير الفرع الرئيسي |
| `callcenter` | `123456` | كول سنتر |
| `kitchen1` | `123456` | مطبخ الفرع الرئيسي |
| `kitchen2` | `123456` | مطبخ فرع مدينة نصر |
| `driver1` | `123456` | طيار |

> ⚠️ **مهم:** دي حسابات تجريبية. غيّر كلمة سر `admin` فوراً من **الإعدادات**، وامسح أو عدّل باقي الحسابات من **المستخدمين**، وعدّل الفروع والمنيو ببياناتك.

## 📱 الربط مع الموبايل

### على نفس الواي فاي (السيرفر على كمبيوتر في المطعم)
لما تشغل السيستم هيطبعلك عنوان زي:
```
من الموبايل:     http://192.168.1.10:3000
```
افتح العنوان ده من متصفح أي موبايل متوصل على **نفس الواي فاي** وسجل دخول.

### تثبيته كتطبيق على الموبايل
من المتصفح (كروم على أندرويد / سفاري على آيفون) افتح القائمة واختار **"إضافة إلى الشاشة الرئيسية" / Add to Home Screen** - هيظهر كأيقونة ويفتح زي أي تطبيق.

> ملحوظة: التثبيت الكامل كتطبيق (PWA) محتاج الموقع يكون `https` أو `localhost`. على الشبكة المحلية بـ `http` السيستم هيشتغل عادي من المتصفح، أو استخدم تطبيق الأندرويد.

### تطبيق أندرويد / آيفون حقيقي
فولدر **`mobile/`** فيه مشروع تطبيق جاهز بنفس الواجهة. الخطوات في [`mobile/README.md`](mobile/README.md).

## 🌍 الفروع في أماكن مختلفة؟ (تشغيل السيستم على النت)

لو الفروع في أماكن مختلفة، لازم السيرفر يبقى على النت عشان كل الفروع توصله. أسهل الطرق:

**1. سيرفر VPS** (DigitalOcean / Hetzner / Contabo أو أي استضافة فيها Node.js):
```bash
git clone <الريبو>  &&  cd restaurant-system
npm install --omit=dev
cp .env.example .env      # وعدّل JWT_SECRET
npm install -g pm2
pm2 start npm --name restaurant -- start
pm2 save && pm2 startup
```
وبعدين اربط دومين وفعّل https (مثلاً بـ Caddy أو Nginx + Let's Encrypt).

**2. Docker:**
```bash
docker compose up -d --build
```
البيانات بتتحفظ في فولدر `data/`.

> أي استضافة تختارها لازم يكون فيها **مساحة تخزين دائمة** لفولدر `data/` (قاعدة البيانات والصور).

## 👥 الأدوار والصلاحيات

| الدور | يقدر يعمل إيه |
|---|---|
| **مدير عام** | كل حاجة |
| **مدير فرع** | لوحة تحكم فرعه، تسجيل طلبات، متابعة وتحديث وإلغاء طلبات فرعه، تعيين الطيارين، العملاء |
| **كول سنتر** | تسجيل طلبات لأي فرع، يشوف كل الطلبات، تحويل طلب لفرع تاني، إلغاء، العملاء |
| **موظف فرع / مطبخ** | يشوف طلبات فرعه ويحدث حالتها |
| **طيار** | يشوف الطلبات المسندة له بس ويحدث "خرج للتوصيل" و"تم التسليم" |

من صفحة **الأدوار والصلاحيات** تقدر تعدل أي دور أو تعمل دور جديد (مثلاً "كاشير") وتختار صلاحياته.

> موظف الفرع ومدير الفرع لازم يتحدد لهم **فرع** في صفحة المستخدمين.

## 💾 النسخ الاحتياطي

كل البيانات في فولدر **`data/`**:
- `restaurant.db` ← قاعدة البيانات
- `uploads/` ← صور الأصناف

خد نسخة من الفولدر ده بشكل دوري (وقف السيستم الأول أو انسخ الـ 3 ملفات `restaurant.db*` مع بعض).

لمسح كل البيانات والرجوع للبيانات التجريبية: `npm run reset-db`

## ⚙️ الإعدادات (`.env`)
انسخ `.env.example` باسم `.env`:

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | البورت |
| `HOST` | `0.0.0.0` | يقبل اتصال من أجهزة الشبكة |
| `JWT_SECRET` | يتولد تلقائياً | مفتاح تسجيل الدخول |
| `TOKEN_EXPIRES` | `7d` | مدة بقاء تسجيل الدخول |
| `DB_FILE` | `data/restaurant.db` | مكان قاعدة البيانات |
| `TZ` | توقيت الجهاز | المنطقة الزمنية للتقارير (مثلاً `Africa/Cairo`) |

## 🗂️ هيكل المشروع
```
restaurant-system/
├── start.bat / start.sh      ← تشغيل بدبل كليك
├── server/                   ← السيرفر (Node.js + Express + Socket.IO + SQLite)
│   ├── index.js              ← نقطة البداية
│   ├── db.js                 ← قاعدة البيانات والبيانات الافتراضية
│   ├── auth.js               ← تسجيل الدخول والصلاحيات
│   ├── realtime.js           ← الإرسال اللحظي للفروع
│   ├── constants.js          ← الصلاحيات والحالات
│   └── routes/               ← الـ API (orders, menu, customers, branches, users, roles, dashboard...)
├── public/                   ← الواجهة (كمبيوتر + موبايل)
│   ├── index.html
│   ├── track.html            ← صفحة متابعة الطلب للعميل
│   ├── css/app.css
│   └── js/                   ← core.js, app.js, pages/*
├── mobile/                   ← تطبيق أندرويد / آيفون (Capacitor)
├── tests/                    ← اختبارات تلقائية (npm test)
├── docs/API.md               ← توثيق الـ API (لو هتعمل تطبيق تاني)
├── Dockerfile / docker-compose.yml
└── data/                     ← قاعدة البيانات والصور (بتتعمل تلقائياً)
```
